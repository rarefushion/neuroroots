# Prototype
An easy place to put scattered WIP files.

**Workflow:**
1. Branch from `main` with a descriptive name: `prototype/<idea>-<author>`
2. Keep the branch's purpose as clear and concise as possible.
3. Develop in your branch. Use whatever structure makes sense there.
4. When the idea matures, promote it:
   - If it becomes a model → move to `models/`
   - If it becomes a benchmark → move to `benchmarks/`
5. Merge the promotion into `main`
6. I recommend deleting the prototype branch or prefix with `archive/` e.g. `archive/prototype/<idea>-<author>`

**Never commit directly to `main` under `prototypes/`.**
