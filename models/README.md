# Models
Model code, trained weights, configurations, and associated evaluation data.

- Each model resides in its own subdirectory `models/<optional sub dir>/name/`.
- Include a `README.md` including:
    1. What the models goal is and Why it matters.
    2. How your model aims achieves that goal.
    3. Creation, Training and Evaluation instructions.
- Evaluation outputs (e.g., benchmarks, logs) go in `models/<optional sub dir>/name/eval/`.
